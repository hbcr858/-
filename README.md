# 钢铁森林品牌网页

这是最新修改版的独立静态网站源码，包含原稿 Logo、精简后的装饰线条、钢铁抱枕鼠标及页面动效。

## 文件结构

```text
index.html          网页入口与文字内容
css/
  style.css         主样式、响应式布局和动效
  brand.css         原稿 Logo 和减少细线的样式调整
js/
  app.js            鼠标、滚动渐显和展开交互
images/             原稿 Logo、IP 图形、纸张肌理和情绪板图片
README.md           使用说明
```

## 本地查看

双击 index.html，即可用浏览器查看。无需安装依赖或构建。
分享或上传时请保留整个文件夹，不能只发送 index.html。
手机等触屏设备不显示自定义鼠标；桌面鼠标设备可显示钢铁抱枕光标。

## 编辑

修改文字：编辑 index.html。
修改外观：编辑 css/style.css 或 css/brand.css，后者优先覆盖同名样式。
修改交互：编辑 js/app.js。
替换图片：放入 images/，并更新 HTML 或 CSS 中对应的相对路径。
Logo 图片直接提取自提供的品牌设计原稿。

## 部署

本网站是纯静态页面。将本文件夹中的全部内容上传到静态网站托管服务，并将 index.html 所在目录设为发布目录即可，无需构建命令。
